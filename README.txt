Color Accent — Android版 (PWA)

この版は、参照したAccentの公開仕様をもとにしたAndroid向けの独自実装です。

主な機能
- ギャラリーから写真を選択
- カメラ撮影
- 写真をタップしてアクセント色を選択
- Range / Feather 調整
- 写真全体 / ブラシ範囲への適用
- ブラシの塗る / 消す
- モノクロ Tone / Contrast
- 最近使った色を最大10色保存
- HEX / RGB表示
- 原寸 / 1:1 / 4:5 / 3:4 / 9:16で書き出し
- 白 / 黒フレーム
- 共有 / PNG / JPEG保存
- Android Chromeからホーム画面へインストール可能

使い方
1. GitHub PagesなどHTTPSで公開
2. AndroidのChromeで開く
3. メニュー → 「ホーム画面に追加」または「アプリをインストール」
4. 「写真を選ぶ」または「カメラで撮る」

注意
- 元アプリと同一のコード・UI・画像資産をコピーしたものではありません。
- 公開ストア版Accentの最新仕様には動画対応などがありますが、この初版は写真編集を中心にしています。
